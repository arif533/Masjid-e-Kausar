# Masjid-e-Kausar
🕌 Masjid-e-Kausar Community Web App — Mobile-first web app for Masjid-e-Kausar, Vijayawada. Features live prayer times, Ramadan timetable, Zakat calculator with live gold/silver rates, events board, donation tracker, admin dashboard with AI assistant, and UPI payments. Role: Solo Developer.
